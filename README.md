# Расписание для Котёнка ♡

Небольшой адаптивный сайт с расписанием учебной группы 212 ЛД на период 01.09.2026–14.01.2027.

## Что есть на сайте
- При открытии выбирается текущая дата, если она входит в период расписания. Если текущая дата за пределами периода, выбирается ближайшая граница периода.
- Можно перейти на любой день через календарь, стрелки или ленту дней недели.
- По умолчанию выбрана подгруппа № 1. Можно выбрать № 2 или № 3; общие пары отображаются у всех подгрупп.
- Включены основные пары, факультативы, учебные практические занятия и список преподавателей.
- Сайт не требует сервера или сборки. Он сделан на HTML, CSS и JavaScript.

## Как опубликовать бесплатно на GitHub Pages
1. Создайте репозиторий на GitHub, например `kotenok-schedule`.
2. Распакуйте архив и загрузите **содержимое папки**, чтобы `index.html`, `styles.css` и `app.js` находились в корне репозитория.
3. Откройте в репозитории **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**, branch `main` и folder `/(root)`, затем нажмите **Save**.
5. Через некоторое время GitHub Pages покажет ссылку вида `https://ВАШ-ЛОГИН.github.io/kotenok-schedule/`. Отправьте её девушке.

После изменений в файлах достаточно снова загрузить их в репозиторий — GitHub Pages обновит сайт автоматически.

## Важная заметка по исходнику
В исходном документе две даты `06.09` указаны внутри раздела «Вторник» для занятий по анатомии и физиологии. Я сохранил эти даты ровно как в файле, поэтому сайт покажет их 6 сентября. Если это опечатка и имелось в виду `08.09`, замените оба `06.09` на `08.09` в соответствующих строках `app.js`.

Шрифт загружается с Google Fonts; если он недоступен, сайт использует системные шрифты.
